## 6. 当前如何准备答辩演示

推荐先在桌面端项目目录执行：

```bash
npm run demo:seed:clean
```

这个命令会一键准备：
- 示例聊天
- 任务卡
- safe actions
- active reminder plan
- active study roadmap
- active file workspace
- 课程表
- 待审批请求
- Activity 时间线

## 7. 当前阶段建议

当前建议：
- 优先做演示走查
- 优先整理答辩说明
- 优先准备演示数据

当前不建议：
- 继续扩大量新功能
- 把 Android 推进到高风险控制层
- 把后续规划内容强塞进当前毕业设计范围
