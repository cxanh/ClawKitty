# ClawDesk 产品功能清单 v1（方向校正版）

## 文档速览

这份文档专门说明：
- 早期功能清单与优先级
- 哪些页面曾被定义为 v1 核心
- 作为历史范围参考的价值

最后更新：2026-03-12


## 1. 文档目的

这份文档用于把新的产品方向落实到功能范围上。

新的统一前提是：

`ClawDesk 是面向大一新生的个人 Agent 助手产品。`

因此功能优先级不再以“系统面板完整度”为第一标准，而是以：
- 是否能帮助用户与 Agent 沟通
- 是否能让用户理解 Agent 在做什么
- 是否能安全地给 Agent 布置任务
- 是否能让用户看懂模型 / 技能 / 工具边界

作为第一标准。

## 2. 版本边界

## 2.1 v1.0 目标

v1.0 不是做全量远程控制，而是先完成：

`一个可安装、可聊天、可查看任务与能力边界的桌面 Agent 主站。`

## 2.2 v1.1 目标

v1.1 再把 Android 端推进为：
- 移动聊天入口
- 移动任务下发入口
- 移动状态查看入口

## 2.3 v1.2 目标

v1.2 再继续做：
- 学习场景模板
- 更强的自动化
- 更完整的审批与回顾

## 3. 用户角色

### 3.1 个人用户（主角色）

典型画像：
- 刚进大一的新生
- 不想学习复杂系统配置
- 想把 Agent 当作会帮忙做事的助手

核心诉求：
- 跟 Agent 聊天
- 给 Agent 下任务
- 知道 Agent 在做什么
- 看懂为什么成功 / 失败

### 3.2 移动端陪伴用户

核心诉求：
- 不在电脑前时，也能看 Agent 状态
- 用手机给 Agent 发起任务
- 看审批进度和结果

### 3.3 高级用户（非主角色）

会关心：
- Browser Relay
- 进程操作
- 更细的工具权限
- 调度和自动化

这些能力需要保留，但不作为首页主叙事。

## 5. v1.0 必做功能

## 5.1 新手引导

### F-001 首次启动引导

功能说明：
- 用自然语言解释 App 当前状态
- 引导用户完成首启配置
- 明确“下一步能做什么”

验收标准：
- 小白首次打开不需要先理解 OpenClaw / Relay / Runtime
- 首页能告诉用户当前是否已经可以开始使用 Agent

### F-002 Base URL / 本地环境说明

功能说明：
- 桌面端说明本地 Runtime 与应用数据目录
- Android 端支持配置桌面 Runtime 地址

验收标准：
- 用户知道 App 连接的是哪台电脑、哪个地址
- 配置错误时能给出可执行提示

## 5.2 Chat

### F-101 桌面端聊天页

功能说明：
- 桌面端提供统一聊天入口
- 用户可以通过自然语言提问与布置任务
- 支持查看 Agent 回复、当前任务状态和错误提示

验收标准：
- 用户可以在桌面端直接与 Agent 对话
- 聊天不是“装饰页”，而是主入口之一

### F-102 对话中任务理解与确认

功能说明：
- Agent 接到任务后，能把理解结果显示给用户
- 高风险动作前要求确认

验收标准：
- 用户能看懂 Agent 将要做什么
- 需要确认时有明确交互

## 5.3 Tasks

### F-201 当前任务中心

功能说明：
- 展示正在进行、等待中、已完成、失败的任务
- 任务可以来自聊天，也可以来自自动化

验收标准：
- 用户能看清 Agent 当前最重要的 3 到 5 个任务

### F-202 任务历史与状态分类

功能说明：
- 任务要有状态、摘要、更新时间、失败原因

验收标准：
- 用户能快速回答“Agent 刚刚做了什么”

## 5.4 Activity

### F-301 Agent 活动流

功能说明：
- 展示最近动作、任务步骤、异常、审批

验收标准：
- 活动流要比日志更好懂
- 小白能从活动流理解 Agent 的工作过程

### F-302 审批与异常提示

功能说明：
- 高风险操作需要审批
- 错误要先显示人话解释，再给技术细节

## 5.5 Capabilities

### F-401 模型概览
- 当前可用模型
- 当前模型状态
- 推荐使用场景

### F-402 Skill 概览
- 当前可用技能
- 技能描述
- 技能启用状态

### F-403 Tool 概览
- 当前可用工具
- 工具作用
- 是否需要授权

验收标准：
- 用户能回答“现在 Agent 能做什么”
- 不要求用户理解内部实现细节

## 5.6 Device / Mobile Support

### F-501 主机状态摘要
- Runtime 在线状态
- 主机名 / 平台 / 心跳
- 必要时显示资源摘要

### F-601 配对中心
- 创建移动端配对会话
- 查看待审批请求
- 管理 scope

## 6. v1.1 重点功能

- Android 聊天入口
- Android 任务下发
- Alerts 页面
- Skills / Tools / Models 详情页
- 自动化任务入口增强
- 移动端审批状态与结果页

## 7. 暂不进入第一版的功能

以下能力继续保留在规划里，但不进入第一版核心发布范围：
- 完整进程管理与高风险控制
- Browser Relay 的复杂远程控制面板
- 提供者配置的深度编辑
- 完整日志检索系统
- 多用户共享协作

## 8. v1.0 页面建议

桌面端建议主导航调整为：
1. `Home`
2. `Chat`
3. `Tasks`
4. `Activity`
5. `Capabilities`
6. `Devices`
7. `Settings`
8. `Logs`

Android 端建议主导航调整为：
1. `Home`
2. `Chat`
3. `Tasks`
4. `Pairing`
5. `Settings`

## 9. 一句话结论

ClawDesk v1 的核心不是“功能面板越多越好”，而是：

`让小白用户能和自己的 Agent 对话、看懂它、信任它、逐步把任务交给它。`
